Experiment 1 – VirtualBox and different operating systems
Software: Oracle VirtualBox
Operating systems: Ubuntu and another OS flavour such as Fedora or Debian.

Steps:
1. Download and install VirtualBox on Windows.
2. Download the Ubuntu ISO file from Ubuntu's official website.
3. Open VirtualBox and click New.
4. Enter the VM name Ubuntu.
5. Select the downloaded Ubuntu ISO file.
6. Allocate RAM and create a virtual hard disk. Use at least 4 GB RAM if your laptop has enough memory.
7. Start the VM and complete the Ubuntu installation.
8. Repeat the process for another OS flavour if your practical requires multiple OS installations.
9. Take screenshots of the VirtualBox manager and running operating systems.
The actual practical is performed through the VirtualBox interface; there is no Python code required for installing an operating system. Oracle's guide explains creating a VM and selecting an ISO image. 
Oracle Documentation+1







Experiment 2 – Install C compiler in the virtual machine
Software: Ubuntu VM + GCC compiler.

Steps:
1. Start the Ubuntu VM created in Experiment 1.
2. Open the Ubuntu Terminal.
3. Install GCC:

sudo apt update
sudo apt install gcc -y


4. Check the compiler:
gcc --version


5. Create a C file:
nano program.c


6. Paste this corrected program:

#include <stdio.h>

int main() {
    int a, b, sum;

    printf("Enter two numbers: ");
    scanf("%d %d", &a, &b);

    sum = a + b;

    printf("Sum = %d\n", sum);

    return 0;
}



7. Save the file using Ctrl+O, Enter, and Ctrl+X.
8. Compile and execute:
gcc program.c -o program
./program


Sample output:
Enter two numbers: 10 20
Sum = 30


This is an actual C compiler running inside your Ubuntu virtual machine.

Experiment 7 – Transfer files from one virtual machine to another
Software: VirtualBox + Two Ubuntu VMs + SSH/SCP.

Steps:
1. Open VirtualBox.
2. Create two Ubuntu VMs named VM1 and VM2.
3. Start both VMs and connect them to the same network (for example, Bridged Adapter, if your network allows it).
4. In both Ubuntu terminals, install SSH:
sudo apt update
sudo apt install openssh-server -y


5. In VM2, check its IP address:
hostname -I


6. In VM1, create a sample file:
echo "Hello, this file is transferred from VM1 to VM2." > sample.txt


7. Transfer the file using SCP:
scp sample.txt username@VM2_IP:/home/username/


Replace username with your Ubuntu username and VM2_IP with the IP address of VM2.
8. Enter VM2's password if prompted.
9. In VM2, verify the file:
cat ~/sample.txt


Expected output:
Hello, this file is transferred from VM1 to VM2.


This demonstrates an actual file transfer between two virtual machines, rather than copying between two folders on one computer.

Experiment 9 – Launch a Virtual Machine using TryStack (OpenStack)
Software: OpenStack Horizon Dashboard (web interface) + an available OpenStack cloud account.

Important: TryStack is an old public OpenStack sandbox and may no longer be available. Do not spend your practical preparation time assuming you can register and launch a VM there. If your college provides an OpenStack dashboard, use that instead. 
GitHub+1


Steps using an available OpenStack dashboard:
1. Get the OpenStack dashboard URL and login credentials from your college or lab administrator.
2. Open the dashboard in your browser and log in.
3. Open Project → Compute → Instances.
4. Click Launch Instance.
5. Enter the instance name, for example MyCloudVM.
6. Select an available Ubuntu image.
7. Select a suitable flavor (CPU, RAM and disk configuration).
8. Select the network and key pair provided by your lab.
9. Click Launch Instance.
10. Wait until the instance status becomes Active.
11. Open the instance details or console to verify that it has launched.
Expected output: An Ubuntu virtual machine appears in the Instances list with an Active status.

OpenStack's official user guide explains the instance launch process. 
OpenStack Docs+1
